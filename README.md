# Лабораторная работа №2

- **Макет:** [To-Do List (Community) в Figma](https://www.figma.com/design/U09ssoBkhIpaSLmO5v0AQ7)
- **Приложение:** [https://romch33tos.github.io/web-development-lab2/](https://romch33tos.github.io/web-development-lab2/)

## Возможности

- Добавление задачи с заголовком и описанием (через форму, работает Enter)
- Отметка задачи как выполненной (клик по чекбоксу или пробел на карточке)
- Редактирование задачи (модальное окно, сохранение по Enter, клику мимо или кнопке Save)
- Удаление задачи с подтверждением (модальное окно Alert to Delete)
- Сохранение в `localStorage` — данные переживают перезагрузку
- Отдельное оформление пустого состояния («No tasks»)
- Полное управление с клавиатуры (Tab, Space, Enter, Escape)
- Меню Share с иконками соцсетей
- Адаптивная вёрстка (проверено на 360, 768, 1280 px)

## Структура проекта

- `index.html` — разметка, шаблон задачи (`<template>`), модальные окна
- `css/style.css` — токены, компоненты, адаптив, стили модалок
- `js/storage.js` — чтение и запись `localStorage` с защитой от ошибок
- `js/state.js` — модель данных, функции `addTask`, `toggleTask`, `removeTask`, `editTask`
- `js/view.js` — отрисовка DOM по состоянию
- `js/handlers.js` — обработчики событий (клики, ввод, клавиатура)
- `js/modals.js` — управление модальными окнами (Delete, Edit, Share, Info)
- `js/main.js` — точка входа, связывает состояние, отображение и события
- `img/icons/` — SVG-иконки из макета

## Модель данных

Задача — объект с полями:
- `id` — уникальный идентификатор (`crypto.randomUUID()`)
- `title` — заголовок (обязательный, до 100 символов)
- `body` — описание (опционально, до 200 символов)
- `done` — признак выполнения (boolean)
- `createdAt` — метка времени создания

## Принятые решения

1. **Чекбокс выполнения:** в макете отсутствует, но добавлен, так как входит в минимальный набор требований методички. Стилизован в цветах макета.
2. **Сохранение при редактировании:** реализовано в модальном окне по кнопке Save, клавише Enter и клику вне окна (blur).
3. **Длинный текст без пробелов:** переносится благодаря `overflow-wrap: anywhere`, горизонтальной прокрутки нет.
4. **Сообщение об ошибке:** выводится под формой, объявляется через `aria-live="polite"`. Всплывающие окна `alert()` не используются.
