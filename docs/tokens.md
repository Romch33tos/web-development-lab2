# Словарь дизайн-токенов приложения

## 1. Палитра цветов (Цветовые токены)

*   `--color-bg-main: #1B1A17;` - основной глубокий темный фон приложения (фоны всех экранов, включая iPhone 14 No Tasks).
*   `--color-bg-card: #242320;` - фон интерактивных блоков (карточек задач и полей ввода формы).
*   `--color-accent: #FF8303;` - фирменный ярко-оранжевый цвет для акцентов (границы активной формы, кнопка добавления, иконки удаления).
*   `--color-border-task: #A35709;` - коричнево-бордовый цвет для рамки карточки задачи (состояние по умолчанию на Экране 2).
*   `--color-text-main: #FFFFFF;` - чистый белый цвет для заголовков приложения и иконки "i" в панели инструментов.
*   `--color-text-card: #F0E3CA;` - светло-бежевый оттенок для читаемого отображения заголовков (Title) и описаний (Body) задач внутри карточек.
*   `--color-text-muted: rgba(240, 227, 202, 0.64);` - полупрозрачный бежевый цвет для подсказок в полях ввода (Placeholder).
*   `--color-overlay: rgba(7, 7, 7, 0.89);` - плотный темный оверлей для фона модальных окон Alert (Экран 4) и Share Box (Экран 6).
