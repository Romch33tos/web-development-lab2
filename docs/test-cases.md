# Сценарии ручной проверки

| № | Действие пользователя | Ожидаемый результат | Результат |
|---|---|---|---|
| **1** | **Успешное добавление**<br>Ввести в поле заголовка «Купить хлеб», в описание «В магазине у дома» и нажать Enter или кнопку Add. | Задача успешно появилась в конце списка. Поля ввода очистились. Фокус вернулся на первое поле формы. Текст «Задач пока нет» скрылся. | |
| **2** | **Валидация пустого ввода**<br>Оставить поле заголовка пустым или ввести одни пробелы, затем нажать кнопку «Добавить». | Задача не добавляется. Рядом с полем формы появляется понятное сообщение об ошибке. Инпут получает атрибут `aria-invalid="true"`. | |
| **3** | **Проверка на XSS-уязвимость**<br>Ввести в заголовок или описание строку `<img src=x onerror=alert(1)>`. | Строка отображается на экране как обычный текст. Никакие вредоносные скрипты не выполняются (окно alert не всплывает). | |
| **4** | **Адаптивность и длинный текст**<br>Добавить задачу с непрерывным текстом без пробелов длиной в 100+ символов и переключить режим устройства на ширину 360px. | Текст автоматически переносится на новые строки. Горизонтальная прокрутка страницы отсутствует. Кнопки не вылезают за границы. | |
| **5** | **Выполнение задачи**<br>Кликнуть мышкой по чекбоксу задачи или нажать на него клавишей Пробел. | Задача помечается как выполненная. К карточке добавляется класс `task--done`, текст визуально зачёркивается и становится полупрозрачным. | |
| **6** | **Открытие панели инструментов (Экран 3)**<br>Кликнуть по тексту или области карточки задачи. | Под карточкой раскрывается панель Tools с тремя кнопками: Share, Info, Edit. При повторном клике панель скрывается. | |
| **7** | **Модальное окно удаления (Экран 4)**<br>Нажать на кнопку удаления (крестик) на карточке задачи. | Задача пока не удаляется. Поверх интерфейса открывается темный оверлей и модальное окно Alert с вопросом о подтверждении. | |
| **8** | **Отмена удаления в Alert**<br>В открытом модальном окне удаления нажать кнопку «Отмена» или кликнуть на оверлей. | Модальное окно скрывается. Задача остается на своем месте в списке. Фокус возвращается на карточку задачи. | |
| **9** | **Подтверждение удаления**<br>В открытом модальном окне удаления нажать кнопку «Удалить». | Задача полностью исчезает из списка. Окно закрывается. Если задач больше нет, на экране мгновенно появляется надпись «Задач пока нет». | |
| **10** | **Вход в режим редактирования (Экран 5)**<br>Открыть панель инструментов задачи и нажать кнопку Edit (карандаш). | Текстовая область карточки скрывается. Вместо неё появляются инпуты, в которые уже подставлен текущий заголовок и описание задачи. Фокус программно переносится в инпут заголовка. | |
| **11** | **Сохранение при редактировании**<br>Изменить текст в инпутах редактирования и нажать Enter или кликнуть мимо полей (blur). | Изменения успешно применились, инпуты скрылись, на экране отображается обновленный текст задачи. | |
| **12** | **Отмена редактирования**<br>В режиме редактирования карточки нажать клавишу Escape. | Карточка возвращается в обычный режим просмотра. Все внесенные изменения сбрасываются, текст остается прежним. | |
| **13** | **Нижняя панель Share Box (Экран 6)**<br>Открыть панель инструментов задачи и нажать кнопку Share. | Открывается темный оверлей, и снизу экрана выезжает аккуратная панель Share Box с кнопками социальных сетей. | |
| **14** | **Сохранение в хранилище**<br>Добавить несколько задач, отметить одну из них и перезагрузить страницу браузера. | Все задачи, их порядок и статусы выполнения полностью восстанавливаются после перезагрузки. | |
| **15** | **Отказоустойчивость хранилища**<br>Во вкладке Application -> Local Storage заменить сохраненную JSON-строку на случайный текст (например, `abc`) и перезагрузить страницу. | Приложение корректно обрабатывает ошибку через `try...catch`. Страница не ломается, консоль выдает предупреждение, а приложение запускается с чистым пустым списком. | |
